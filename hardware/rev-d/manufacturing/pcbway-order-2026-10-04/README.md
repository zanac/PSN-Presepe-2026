PCB options chosen: single pieces, 300 x 180 mm, quantity 5, 2 layers, FR-4 TG150,

HASL lead-free (ENIG substitution allowed), tented vias, 2 oz finished copper,

the bottom), alternatives accepted for passives only (see the remarks below).

Remarks sent with the order:

> vias. 2 oz copper required. Please send DFM results before production.
